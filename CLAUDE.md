# Правила Милы

- Не создавать лишних файлов и документов. Хранить только то, что нужно, чтобы выпустить ролик (код движка, сцены, сам ролик). После выхода ролика его рабочие файлы удалять.
- Переводы, пересказы, пояснения, отчёты — только в чате, на русском, никогда не в файлах.
- Озвучка: бесплатный Kokoro (`finance/engine/tts_kokoro.py`), голос am_michael, медленно. Кредиты ElevenLabs не тратить.
- Финансовый канал: англоязычная аудитория всех стран, не только США. Персонаж Finn (`finance/engine/character.py`) — взрослый, утверждён.
