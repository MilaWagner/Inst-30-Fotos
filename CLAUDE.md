# Правила работы (обязательно для каждой сессии)

## Сохранность результатов — главное правило
- Контейнер сессии временный: всё, что лежит только в нём, пропадёт.
- КАЖДЫЙ готовый результат (ролик, обложка, озвучка, пробы голосов, сценарий) сразу после
  создания загружать на Google Drive пользователя (коннектор Google Drive, `create_file`,
  `base64Content` = ссылка на файл `sha256:<hash>:<абсолютный путь>`), не дожидаясь просьбы.
- Ролики Ольги (FitLine): папка Drive «Ольга FitLine — ролики», id `1d_wuutW-hkTw0DBB_N21Yek_BJ_Hb7vs`.
- Задача не считается выполненной, пока файл не загружен на Drive и пользователь не получил ссылку.
- Кредиты Higgsfield не тратить без прямого разрешения.

## Работа с пользователем
- Ничего не делать сверх запрошенного; ждать указаний.
- Сценарии и стратегию продаж для клиентов (Ольга) — только как черновик на согласование.
- Факты о продуктах брать только с официального сайта (fitline.com), формулировки эффекта —
  только разрешённые в ЕС (как на сайте). Ничего не выдумывать.
- Хуки и заголовки: Google Drive «Примеры продающих ХУКОВ.pdf»,
  «50 заголовков, после которых хочется открыть описание продукта.pdf»,
  «30 проблем, за решение которых люди уже готовы платить.pdf».
